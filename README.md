# Garfix ERP — نظام إدارة الموارد الذكي

<div dir="rtl">

**نظام ERP عربي RTL متكامل للسوق المصري** — فواتير ضريبية (ض.ق.م 14%)، عملاء، **موردون ومشتريات بتكلفة متوسط مرجح**، مخزون، مصروفات، تحليلات وتقارير مالية، وكلاء أذكياء AI، ومستخدمون بأدوار وصلاحيات.

Built with **Next.js 16 + Prisma + SQLite + TanStack Query + shadcn/ui + Tailwind** — واجهة عربية بالكامل بخط Cairo وثيم زمردي فاتح/داكن.

## 🧩 ما الجديد في المرحلة 6؟

- **دورة المشتريات الكاملة**: `مسودة → مطلوبة → مستلمة → مدفوعة جزئياً/كاملة` — إنشاء فاتورة شراء ببنود من منتجات المخزون أو بنود حرة، بضريبة مورد اختيارية.
- **الاستلام بترحيل المخزون بالمتوسط المرجح**: عند الاستلام تدخل الكميات المخزون ويُحدّث `cost` تلقائياً: `(الرصيد × التكلفة + الوارد × تكلفة الشراء) ÷ (الرصيد + الوارد)` — فتصبح COGS وقائمة الدخل دقيقة بتكلفة حقيقية لا تقديرية.
- **الإلغاء العكسي**: إلغاء فاتورة مستلمة يُرجع الكميات للمخزون تلقائياً.
- **مدفوعات الموردين**: دفعات (نقدي/بنكي/محفظة/شيك) على الفواتير المستلمة أو المطلوبة مع مرجع وتاريخ، والانتقال التلقائي لـ «مدفوعة جزئياً» ثم «مدفوعة».
- **سجل الموردين**: بطاقة مورد كاملة (شركة، سجل ضريبي، مدينة) + أرصدة ومستحقات ومتأخرات كل مورد — والحماية من حذف مورد له فواتير (يُعطّل بدلاً من الحذف).
- **وكيل «مساعد المشتريات» AI**: يحلّل الموردين ومستحقاتهم المتأخرة ويقترح أوامر شراء للمنتجات الناقصة بكميات وتكاليف تقديرية من آخر تكلفة شراء فعلية.
- **تقارير المشتريات**: تبويب جديد — إجمالي المشتريات ومدفوعات الموردين شهرياً + جدول أداء الموردين بنِسب السداد + مستحقات الموردين في الملخص التنفيذي.
- **داشبورد موسّعة**: KPI «مستحقات الموردين» + «مشتريات الشهر» + أعلى الموردين + أحدث فواتير الشراء.
- **صلاحيات**: المشتريات والموردون لمدير النظام والمحاسب فقط (المبيعات لا تراها أصلاً — 403 على الـ API).

## 🧩 ما الجديد في المرحلة 5؟

- **تسجيل دخول وجلسات خادمية**: تجزئة `scrypt` + جلسات في قاعدة البيانات + كوكي `httpOnly` (7 أيام) — لا جلسة = لا API.
- **أدوار وصلاحيات (RBAC)**: `admin / accountant / sales` — حماية على مستوى كل مسار API (`requireUser([...])`) + واجهة مفلترة حسب الدور.
- **إدارة المستخدمين** (مدير): إنشاء/تعديل/إيقاف/حذف حسابات، إعادة تعيين كلمات المرور، حماية آخر مدير نشط.
- **طباعة/PDF للفواتير**: صفحة `/invoice/[id]/print` — تصميم A4 عربي احترافي (ترويسة الشركة، ض.ق.م، المدفوعات) مع «حفظ كـ PDF» من حوار الطباعة.
- **تحصيل واتساب**: زر تذكير على كل فاتورة غير محصلة/متأخرة وعلى بطاقة العميل — يبني `wa.me` برسالة عربية جاهزة (توحيد أرقام مصر 01x → 20x).
- **النسخ الاحتياطي والتصدير** (مدير): نسخة JSON كاملة (استرجاع بنقرة) + CSV لكل جدول بترميز UTF-8 يظهر العربية سليمة في Excel.
- **تتبع المسؤولية**: كل إجراء في سجل النشاط وكل تشغيل وكيل AI يُسجّل ببريد المستخدم المنفّذ.

## 🤖 محرك الوكلاء (Agent Engine)

5 وكلاء متاحون من واجهة «الوكلاء الأذكياء»: **المستشار المالي** · **مساعد المخزون** · **مساعد العملاء** (صياغة رسائل تحصيل) · **مساعد المشتريات** (المرحلة 6: تحليل الموردين واقتراح أوامر الشراء) · **مساعد Garfix**. يجمع كل وكيل سياق الأعمال الحقيقي من قاعدة البيانات (إيرادات، ذمم، مخزون ناقص...) ويحلّله عبر z-ai-web-dev-sdk، ويُسجّل كل تشغيل مع المستخدم والمدة.

## 🗂️ البنية

```
prisma/schema.prisma        # Client/Product/Invoice/InvoiceItem/Payment/Expense/AgentRun/ActivityLog/Setting/User/Session/Supplier/Purchase/PurchaseItem/SupplierPayment
src/lib/auth.ts             # scrypt + جلسات + requireUser (حارس الـ API)
src/lib/roles.ts            # الأدوار والصلاحيات (مشترك خادم/واجهة)
src/lib/agent/engine.ts     # محرك الوكلاء
src/lib/whatsapp.ts         # روابط تحصيل wa.me
src/app/login/page.tsx      # تسجيل الدخول + الدخول السريع
src/app/invoice/[id]/print  # فاتورة A4 للطباعة/PDF
src/app/api/*               # 15 مساراً محمية بالأدوار
src/components/erp/*        # 10 أقسام SPA
scripts/seed.ts             # بيانات سوق مصري واقعية
scripts/dev-daemon.py       # تشغيل خادم dev كـ daemon
```

## 🚀 التشغيل

```bash
bun install
bunx prisma db push          # إنشاء القاعدة
bun run scripts/seed.ts      # بيانات تجريبية
bun run dev                  # http://localhost:3000
```

البيئة التجريبية مبنية على سوق مصري واقعي: 10 عملاء، 12 منتجاً، 42 فاتورة على 6 أشهر، 39 دفعة، 36 مصروفاً (EGP + ض.ق.م 14%).
